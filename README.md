# Навігатор тахеометра

Мобільний вебзастосунок для візуальної навігації по сітці точок на антені. Телефон **не виконує геодезичне вимірювання** — вимірює тахеометр. Телефон лише показує камеру, прив'язує сітку, шукає видиму лазерну пляму, визначає найближчу точку та веде журнал.

## Що підтримується

- камера телефона;
- прямокутні антени;
- круглі та еліптичні антени;
- сучасніший темно-сірий мобільний інтерфейс;
- ручне калібрування по 4 точках;
- ArUco-маркери 0–3;
- експериментальний пошук контуру;
- пошук яскравої або червоної лазерної плями;
- автоматичний вибір найближчої точки сітки;
- ручне підтвердження кнопкою **«Точку знято»**;
- зелений колір для знятих точок, жовтий для незнятих, червоний/білий для активної;
- показ горизонтальних і вертикальних ліній сітки та їх перетинів;
- захист від повторного позначення вже знятої точки;
- журнал з номером точки, рядком, колонкою, часом та координатами лазерної плями;
- експорт CSV;
- збереження журналу у `localStorage`.

## Важливо

У цій версії **немає Bluetooth, Web Bluetooth, COM/Serial, Web Serial або WebSocket-моста**. Підтвердження точки виконується лише вручну оператором після фактичного вимірювання тахеометром.

## Запуск

Для камери потрібен HTTPS або localhost. Найпростіше розмістити папку на HTTPS-сайті або запустити локальний HTTPS dev-server.

На звичайному `http://<IP-телефона>:порт` камера на телефоні може бути заблокована браузером. `localhost` вважається безпечним контекстом лише на тому самому пристрої.

## Калібрування прямокутної антени

Натисніть 4 точки у порядку:

1. лівий верхній кут;
2. правий верхній кут;
3. правий нижній кут;
4. лівий нижній кут.

Після цього сітка будується всередині чотирикутника. Для ручного режиму застосунок намагається відстежувати невеликі зміщення вибраних областей між кадрами.

## Калібрування круглої антени

Кругла антена при нахилі камери виглядає як еліпс, тому калібрування виконується не лише по центру і радіусу, а по 4 крайніх точках:

1. верхня;
2. права;
3. нижня;
4. ліва.

На основі цих точок будується еліптичний контур. Усередині нього створюється сітка з горизонтальних і вертикальних ліній. Точки — це перетини цих ліній, але лише ті, що потрапляють у межі круга / еліпса. Кількість рядів і колонок можна задавати вручну.

## ArUco

Для прямокутної антени:

- ID 0 = лівий верхній;
- ID 1 = правий верхній;
- ID 2 = правий нижній;
- ID 3 = лівий нижній.

Для круглої/еліптичної антени:

- ID 0 = верх;
- ID 1 = право;
- ID 2 = низ;
- ID 3 = ліво.

ArUco-детектор завантажується з CDN `js-aruco2`. Якщо CDN недоступний, ручне калібрування продовжує працювати.

## CSV

Журнал містить поля:

- `point`;
- `row`;
- `column`;
- `time`;
- `laser_x_px`;
- `laser_y_px`;
- `laser_x_norm`;
- `laser_y_norm`;
- `antenna_shape`;
- `confirmation`.

## Практичні зауваження

- Яскраве сонце та блискуча поверхня можуть давати хибні плями.
- Для цього є регулювання порога чутливості.
- Автоекспозиція камери може змінювати видимість лазера.
- Для стабільної прив'язки краще використовувати контрастні мітки або ArUco.
- Експериментальний автоконтур треба візуально перевіряти перед роботою.
